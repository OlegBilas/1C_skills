# Синхронізація 1С-скілів

Цей каталог містить Codex-адаптації зіставлених джерел. Щотижнева звірка проводиться між GitHub-репозиторієм `OlegBilas/1C_skills` та джерелами нижче.

## Правила джерел

- `Source: https://github.com/Nikolay-Shirokov/cc-1c-skills` — оновлювати лише відповідні файли з Codex-гілки `port-codex` або переносити зміни з `main` з адаптацією під Codex.
- `Source: https://github.com/Desko77/claude-code-skills-1c` — оновлювати лише файли, похідні від цього репозиторію; адаптувати Claude Code-специфічні інструкції, шляхи, команди та назви інструментів.
- Маркер джерела у файлі визначає його походження. Якщо маркера немає або походження неоднозначне, не перезаписувати файл за збігом назви чи функціональності.
- Якщо навички перетинаються за функціональністю, змінювати тільки навичку з підтвердженим походженням від відповідного upstream.
- Нові корисні навички додавати окремими каталогами з Codex-сумісним `SKILL.md`; не переносити Claude Code-специфічні інструкції без адаптації.

## Щотижнева процедура

1. Порівняти актуальне дерево GitHub-репозиторію `OlegBilas/1C_skills` з обома upstream-репозиторіями.
2. Перевірити зміни у файлах із підтвердженим маркером джерела.
3. Оновити відповідні файли на GitHub, зберігаючи Codex-адаптації та локальні зміни.
4. Додати відсутні корисні навички після адаптації.
5. Повідомити користувача про фактичні оновлення. ZIP-архів не створювати.
