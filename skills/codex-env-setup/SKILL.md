# Настройка окружения Codex

Помогает проверить и обслужить окружение Codex на локальном компьютере. Подходит для первичной установки и для уже настроенной среды.

## Порядок работы

1. **Сними опись.** Проверь версии доступных CLI, локальные каталоги скилов Codex, конфигурацию MCP, доступные плагины и связанные процессы. Читай конфиги без вывода секретов: показывай имена серверов и наличие ключей, но не значения.
2. **Сверь с задачей.** Отметь отсутствующие, отключенные и недоступные компоненты. Различай установленный компонент и тот, который действительно отвечает.
3. **Подготовь изменения.** Перед записью покажи конкретный список компонентов и файлов, которые изменятся, включая резервную копию или способ отката. Сохраняй пользовательские настройки и изменения; сливай JSON-конфиги вместо полной замены.
4. **Установи выбранные компоненты.** Используй поддерживаемые Codex-плагины и скилы, а также официальные установщики соответствующих инструментов. Не запускай команды из непроверенных источников и не удаляй существующие данные.
5. **Проверь результат.** Для каждого компонента проверь фактическую доступность или версию. Если выполнить проверку нельзя, укажи причину.
6. **Подведи итог.** Перечисли установленные и обновленные компоненты, проверки, оставшиеся проблемы и действия, которые нужны от пользователя.

## Границы

- Инструкции `CLAUDE.md`, каталоги `.claude/` и команды Claude Code не являются настройками Codex; сопоставляй их с `.codex/`, Codex CLI и подключенными инструментами только при явной совместимости.
- Не раскрывай секреты из `.env`, конфигураций MCP, хранилищ ключей или истории команд.
- Не перезаписывай измененные пользователем файлы и не удаляй компоненты в рамках обновления.
- Не утверждай, что MCP-сервер или интеграция работают, пока не получено подтверждение их доступности.
