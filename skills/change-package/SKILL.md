# Пакет ручного внесення змін 1С

Перетвори бажану зміну BSL на зрозумілу інструкцію, яку розробник зможе виконати вручну у Конфігураторі.

## Порядок роботи

1. Знайди повний модуль і процедуру/функцію, яку треба змінити. Використай актуальний вихідний код, а не припущення за назвою.
2. Якщо користувач надав початкову й цільову версії модуля, порівняй їх та відокреми навколишні зміни, які не стосуються задачі.
3. Для кожної правки наведи шлях до об'єкта, назву модуля, точний фрагмент для пошуку та повний фрагмент для вставки чи заміни. Для видалення вкажи точні межі.
4. Збережи директиви компіляції, контекст клієнт/сервер, експортність і порядок параметрів. Не переписуй сусідній код без необхідності.
5. Додай кроки перевірки: компіляція модуля, перевірка синтаксису конфігурації та потрібний сценарій поведінки. Чітко відділи перевірки, які можна виконати лише у робочій інформаційній базі.
6. Виведи пакет змін у послідовності, придатній для ручного виконання. Якщо потрібного коду чи версії бракує, спершу запитай саме цей матеріал.

## Формат результату

Для кожної правки вкажи:

- об'єкт і модуль;
- пошуковий фрагмент, достатній для однозначного знаходження;
- точну дію та текст заміни;
- очікуваний результат;
- крок перевірки.

Не видавай приблизний код за готову інструкцію: познач невідомі місця та не вигадуй рядки контексту.
